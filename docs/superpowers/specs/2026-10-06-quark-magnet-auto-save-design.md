# 夸克磁力链批量自动保存工具 — 设计文档

日期：2026-10-06
状态：已经用户确认

## 1. 背景与目标

用户经常需要批量把磁力链转存到夸克网盘。夸克网盘 PC 客户端会监听剪贴板，检测到磁力链后自动弹出转存弹窗，用户目前手动逐条操作：

1. 复制一条磁力链，等待夸克弹窗；
2. 点击保存按钮（两种情况）：
   - **情况A（未缓存过）**：弹窗右下角只有一个深色按钮「保存至夸克网盘」；
   - **情况B（已缓存过）**：弹窗右下角有两个按钮，点深色的「极速保存至夸克网盘」（不要点蓝色的「高速下载」）；
3. 弹窗自动关闭，复制下一条，重复。

本程序将上述步骤完全自动化：读取 txt 中的磁力链（可能有空行、非磁力链行），逐条复制并自动点击保存。

### 关键约束

- 截图模板取自 4K+150% 缩放电脑，但程序要能在任意分辨率/DPI 的电脑上运行（开发机为 1920+100%）。
- 最终交付**单文件独立 exe**，可拷贝到不同电脑直接使用。
- 已知存在「保存失败」「解析失败」等错误弹窗（暂无截图），程序必须容错。
- 运行期间鼠标会被程序控制，用户接受 Ctrl+C 停止方式，不需要额外热键。

### 用户已确认的决策

| 决策点 | 结论 |
|---|---|
| 异常处理策略 | 重试 1 次，仍失败记入失败清单并继续；结束输出汇总报告 |
| txt 来源 | exe 同目录默认 `磁力链.txt` + 支持拖拽 txt 到 exe 图标 |
| 断点续跑 | 成功链接的 infohash 记入 done.txt，重跑自动跳过已成功项 |
| 运行控制 | 无热键，Ctrl+C 安全停止 |
| 技术方案 | 方案A：全屏截图 + 多尺度模板匹配（弃用 UIA / 窗口句柄方案） |

## 2. 总体架构

单进程 Python 程序，四个模块：

| 模块 | 职责 |
|---|---|
| `link_parser` | 读 txt、正则提取磁力链（`magnet:?xt=urn:btih:[0-9a-zA-Z]{32,40}` 等）、按原顺序去重 |
| `screen_agent` | DPI 感知全屏截图、多尺度模板匹配（OpenCV）、鼠标点击、剪贴板读写（全部经 Win32 API/ctypes） |
| `orchestrator` | 主流程状态机：等弹窗→点按钮→等关闭→记录；重试逻辑 |
| `reporter` | 控制台+文件日志、成功记录 done.txt、异常截图存档 |

## 3. 数据流

```
磁力链.txt → link_parser 提取磁力链（保持顺序、去重）
          → 过滤 done.txt 中已成功项
orchestrator 逐条循环：
  1. 清空剪贴板 → 写入链接 → 读回比对验证
  2. 每 300~500ms 截全屏，多尺度匹配标题模板「使用夸克网盘转存或下载」
     → 弹窗出现（默认超时 20s）
  3. 在弹窗区域内匹配按钮模板：「保存至夸克网盘」或「极速保存至夸克网盘」，
     谁命中点谁（中心点）
  4. 轮询确认弹窗消失（标题模板不再命中，默认超时 30s）→ 记成功，追加 done.txt
  5. 等待 interval_sec（默认 2s）→ 复制下一条
  异常路径：全屏截图存档 → 关闭弹窗（点右上角×；×模板未命中时按弹窗区域右上角几何推算坐标点击；注意：Esc 对夸克弹窗无效）→ 重试 1 次
     → 仍失败记失败，继续下一条
结束：控制台 + 日志文件输出汇总（成功 N / 失败 M / 跳过 K + 失败明细）
```

### DPI 适配

- 程序启动即调用 `SetProcessDpiAwareness(Per-Monitor v2)`，截图与坐标均为物理像素。
- 模板来自 4K+150% 截图（物理像素）。运行时按目标屏 DPI 计算理论缩放系数（如 100% 屏 → ×1/1.5），在该系数 ±20% 范围内小尺度步进微调匹配；任何分辨率均适用。
- 多显示器：截图覆盖整个虚拟屏幕（`SM_XVIRTUALSCREEN` 等）。

## 4. 配置与模板

### 配置文件

与 exe 同名 json（如 `夸克磁力链工具.json`），首次运行不存在时自动生成默认值：

```json
{
  "txt_path": "磁力链.txt",
  "done_file": "done.txt",
  "log_file": "quark_auto_save.log",
  "screenshot_dir": "异常截图",
  "popup_timeout_sec": 20,
  "save_timeout_sec": 30,
  "retry_times": 1,
  "interval_sec": 2.0,
  "match_threshold": 0.8
}
```

### 模板管理

- 从 1.jpg / 2.jpg 裁剪 4 个内置模板：弹窗标题、「保存至夸克网盘」按钮、「极速保存至夸克网盘」按钮、右上角「×」。
- 模板打包进 exe；exe 同目录 `templates/` 下如有同名 png 则**优先使用**——夸克改版后只需截图替换模板文件，无需重新打包。
- 预留 `templates/error_*.png` 命名空间：用户日后提供错误弹窗截图，裁剪后放入即被识别为「已知错误弹窗」，命中立即走失败路径，无需改代码。

## 5. 错误处理矩阵

| 异常 | 检测方式 | 处理 |
|---|---|---|
| txt 无有效链接 | 解析结果为空 | 提示并退出 |
| 剪贴板写入/验证失败 | 读回比对不一致 | 重试 3 次 → 跳过该链接 |
| 弹窗超时未出现 | 标题模板超时无匹配 | 重新复制重试 1 次 → 记「弹窗超时」 |
| 未知弹窗（解析失败等） | 标题出现但按钮超时未命中，或命中 error_* 模板 | 截图存档 → 点右上角×关闭（模板未命中则几何推算）→ 重试 1 次 → 记失败 |
| 保存后弹窗不关闭 | 标题模板持续存在超时 | 截图存档 → 点右上角×关闭（模板未命中则几何推算）→ 重试 1 次 → 记失败 |
| 未来新错误弹窗 | 用户提供截图裁模板放入 templates/ | 命中即走失败路径，无需改代码 |
| Ctrl+C | KeyboardInterrupt | 安全停止，输出已完成进度汇总 |

每次异常自动保存带时间戳与链接序号的全屏截图（如 `异常截图/20261006_143025_第3条.png`）。

## 6. 测试策略

1. **离线模板验证**（开发机）：对 1.jpg / 2.jpg 跑模板匹配，确认按钮定位准确。
2. **模拟弹窗测试**（开发机）：模拟器脚本按目标 DPI 缩放显示 1.jpg / 2.jpg 模拟弹窗，程序走完整流程（点击落在模拟器上），验证匹配、点击坐标、状态机与重试逻辑。
3. **实机验证**（用户夸克电脑）：2~3 条磁力链小批量试跑，核对日志与实际网盘保存结果。

## 7. 打包交付

- 技术栈：Python 3.11 + opencv-python-headless + numpy + Pillow + PyInstaller（`--onefile`）。
- 产物：单个 exe（约 30~50MB）+ 首次运行自动生成同名 json 配置。
- 使用方式：exe 与 `磁力链.txt` 放同目录双击运行；或把 txt 拖到 exe 图标上。
- 固有约束（方案A）：运行期间弹窗区域不能被遮挡或最小化。

## 8. 前提条件（用户环境）

- 夸克网盘 PC 客户端已登录、剪贴板监听（自动弹窗）功能开启。
- 程序运行期间不占用鼠标键盘。
